# ESP32-LED-Modes

Проєкт для ESP32 (Adafruit Metro ESP32-S3) на PlatformIO (Arduino framework, C++).
Світлодіод має три режими роботи, які перемикаються вбудованою кнопкою BOOT.

## Що робить код

- **Режими LED:** вимкнено (стартовий), блимання (500 мс), завжди увімкнено.
- **Перемикання:** кожне натискання кнопки BOOT (GPIO 0) змінює режим по колу:
  вимкнено → блимання → увімкнено → вимкнено.
- **Переривання:** кнопка обробляється через `attachInterrupt` (FALLING).
  ISR лише виставляє прапорець, а вся логіка виконується в `loop()`.
- **Антидребезг:** натискання, що ближчі за 50 мс одне до одного, ігноруються.
- **Без `delay()`:** блимання реалізовано через `millis()`, тому цикл не блокується.
- **Структура:** клас `Led`, строгі типи (`enum class LedState`, `enum class Mode`),
  налаштування зібрані в `struct Config`.
- **Вимірювання продуктивності:** середній час ітерації `loop()` по 1000 ітераціях
  виводиться в Serial (приблизно 2.2 мкс).
